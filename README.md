# Blood Tracking Assistant — ITCC298 Final Capstone

Simple five-page website based closely on the text from Jacob Jackson’s Week 5 PowerPoint. Spelling and grammar have been corrected where necessary. The Application page includes screenshots of the proposed app rather than a functioning prototype.

## Publish to GitHub Pages
1. Create a public GitHub repository.
2. Upload all five HTML files, style.css, and the entire assets folder to the root of the repository.
3. Open Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Visit the published URL and check each page and the image.
5. Submit the URL in a Word document to AMU.
